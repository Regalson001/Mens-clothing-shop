# MenStyle — Men's Clothing Shop

**Wear Better. Live Bolder.**

MenStyle is a modern, responsive men's fashion storefront built with HTML5 and CSS3. It features a premium dark design with gold accents, stylish product cards, clothing categories, promotional sections, and a newsletter signup interface.

The project demonstrates how to create an elegant e-commerce storefront using clean code, responsive layouts, and modern front-end design principles.

**GitHub Repository:** https://github.com/Regalson001/Mens-Clothing-Shop

## 📸 Project Overview

MenStyle is designed for a contemporary men's fashion brand that wants to showcase its clothing collection through an attractive and user-friendly online shopping experience.

The interface combines a dark navy background, gold highlights, high-quality fashion photography, clear typography, and carefully organized product sections to create a premium shopping atmosphere.

## ✨ Features

- **Premium Homepage:** An attractive hero section with a headline, promotional message, and shopping calls to action.
- **Responsive Navigation:** Navigation links for Home, Shop, Categories, About, and Contact.
- **Clothing Categories:** Dedicated visual cards for shirts and polos, jackets, and formal wear.
- **Product Collection:** Product cards displaying clothing images, product names, category labels, ratings, prices, and promotional badges.
- **Interactive Hover Effects:** Smooth transitions on product cards, buttons, and category cards.
- **Benefits Section:** Highlights premium quality, modern style, secure shopping, and easy returns.
- **Promotional Banner:** Encourages visitors to explore the clothing collection.
- **Newsletter Interface:** An email signup form with basic HTML email validation.
- **Professional Footer:** Includes navigation links, customer care information, and store details.
- **Responsive Design:** Adapts to desktop, tablet, and mobile screen sizes.
- **Accessibility Considerations:** Semantic HTML elements, descriptive image alternative text, form labels, and visible keyboard focus styles.

## 🚀 Getting Started

Follow these steps to run the project locally.

### Prerequisites

You need:

- A computer with a modern web browser.
- Visual Studio Code or another code editor.
- Git installed if you want to clone the repository.
- An internet connection for externally hosted fonts and images.

### 1. Clone the Repository

Open your terminal and run:

```bash
git clone https://github.com/Regalson001/Mens-Clothing-Shop.git
```

### 2. Navigate to the Project

```bash
cd Mens-Clothing-Shop
```

### 3. Open in Visual Studio Code

```bash
code .
```

### 4. Run the Website

Open `index.html` in your browser.

Alternatively, install the Live Server extension in Visual Studio Code, right-click `index.html`, and select **Open with Live Server**.

## 📱 Responsive Design

The website uses CSS media queries to adapt its layout to different screen sizes.

- **Desktop:** Full navigation, spacious hero section, three-column category layout, and four-column product grid.
- **Tablet:** Adjusted spacing and a two-column product grid.
- **Mobile:** Compact navigation, vertically arranged categories, responsive product cards, and a single-column layout on smaller screens.

The layout is designed to remain readable and usable across a range of devices.

## ⚙️ Current Functionality and Limitations

This project is a **front-end demonstration**, not a complete production e-commerce application.

Currently implemented:

- Responsive page layouts.
- CSS hover and transition effects.
- Anchor navigation between sections.
- Browser-native email input validation.

Not yet implemented:

- Functional shopping cart or checkout.
- Product search, sorting, and filtering.
- Customer accounts and authentication.
- Backend order processing or payment integration.
- Persistent newsletter subscriptions.
- Inventory and product management.
- Live product ratings or reviews.

The product action buttons currently link to the contact section. The newsletter form does not store submitted email addresses. Product prices, ratings, and promotions are sample content for demonstration purposes.
